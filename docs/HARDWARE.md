# 하드웨어 구성 및 배선

## 구성품

- ESP32 DevKit V1
- PZT 압전 센서 4개
- PZT 보호·증폭·피크홀드용 아날로그 프런트엔드(MCP6004 기반)
- MPU6050 가속도·자이로 센서
- DS3231 RTC 모듈
- 0.91인치 128×32 I2C OLED(주소 `0x3C`)
- microSD 모듈
- 초록·노랑·빨강 LED와 각 220Ω 직렬저항
- 3.3V 논리 입력을 지원하는 능동 부저 모듈

## ESP32 핀맵

| 장치 | 신호 | GPIO | 비고 |
|---|---|---:|---|
| PZT | Front-Left | 32 | ADC1 |
| PZT | Front-Right | 33 | ADC1 |
| PZT | Rear-Left | 34 | ADC1, 입력 전용 |
| PZT | Rear-Right | 35 | ADC1, 입력 전용 |
| I2C | SDA | 21 | OLED·MPU6050·DS3231 공용 |
| I2C | SCL | 22 | OLED·MPU6050·DS3231 공용 |
| 부저 | Signal | 25 | 능동 부저 |
| LED | Green | 26 | 220Ω 직렬저항 |
| LED | Yellow | 27 | 220Ω 직렬저항 |
| LED | Red | 14 | 220Ω 직렬저항 |
| microSD | SCK | 18 | VSPI |
| microSD | MISO | 19 | VSPI |
| microSD | MOSI | 23 | VSPI |
| microSD | CS | 13 | 4 MHz로 초기화 |

모든 모듈과 ESP32는 GND를 공통으로 연결합니다. 전원 전압은 사용하는 모듈의 실제 사양을 확인한 뒤 연결합니다.

## I2C 주소

| 장치 | 주소 | 설정 |
|---|---:|---|
| OLED | `0x3C` | 기본 주소 |
| MPU6050 | `0x69` 권장 | AD0를 3.3V에 연결 |
| DS3231 | `0x68` | 고정 주소 |

MPU6050을 기본 주소 `0x68`로 사용하면 DS3231과 충돌합니다. 정상 구성은 MPU6050 `0x69` + DS3231 `0x68`입니다. 펌웨어는 RTC가 없을 때의 기존 `0x68` MPU6050도 탐색하지만, 두 장치를 동시에 쓸 때는 반드시 주소를 분리합니다.

## PZT 입력 회로 주의

PZT는 순간적으로 ESP32 허용 전압을 넘는 신호를 만들 수 있으므로 ADC에 직접 연결하지 않습니다.

- 입력 보호 저항과 0~3.3V 전압 클램프를 사용합니다.
- MCP6004는 3.3V 단일 전원으로 구동합니다.
- 증폭·정류·피크홀드 출력이 항상 0~3.3V인지 멀티미터와 오실로스코프로 먼저 확인합니다.
- ADC 연결 전 각 채널의 무입력 전압, 가벼운 탭 응답, 복귀 시간을 측정합니다.
- 네 채널의 회로와 배선 길이는 가능한 한 동일하게 유지합니다.
- 센서 케이블과 고전류 전원선은 떨어뜨리고, 필요하면 차폐·꼬임 배선을 적용합니다.

## 물리 배치 기준

펌웨어에서 바라본 좌표는 다음과 같습니다.

```text
차량/시험판 전방

FL (GPIO32) ───────── FR (GPIO33)
     │                    │
     │       CENTER       │
     │                    │
RL (GPIO34) ───────── RR (GPIO35)

차량/시험판 후방
```

실제 센서에는 `FL`, `FR`, `RL`, `RR` 라벨을 붙이고 배선 양쪽에도 같은 표기를 합니다. 장착 후 각 센서 바로 위를 차례로 가볍게 두드려 시리얼 출력의 최대 채널이 물리 위치와 일치하는지 확인합니다.

## 최초 구동 순서

1. ESP32만 연결해 펌웨어 부팅을 확인합니다.
2. I2C 스캔으로 OLED `0x3C`, MPU6050 `0x69`, DS3231 `0x68`을 확인합니다.
3. microSD 카드 포맷과 `/impact_log_v3.csv` 생성을 확인합니다.
4. PZT 프런트엔드 출력 전압 범위를 계측합니다.
5. PZT 4채널을 연결하고 부팅 보정을 수행합니다.
6. 안내에 따라 채널별 탭 자가시험을 통과합니다.
7. 센서 위치 매핑을 확인한 후에만 낙하 실험을 시작합니다.

## 안전 범위

이 구성은 축소 시험판의 저에너지 충격 실험용입니다. 실제 차량, 고전압 배터리 팩, 화재·열폭주 시험에는 사용하지 않습니다. 실제 차량 안전 판단에는 인증된 장비와 전문가 점검이 필요합니다.
