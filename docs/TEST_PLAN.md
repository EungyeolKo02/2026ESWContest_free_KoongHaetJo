# 시험 설계 및 검증 결과

## 검증 목적

EV-BLACKBOX의 검증 목표는 실제 EV 배터리 손상을 진단하는 것이 아니라, 축소 시험판에서 다음 기능이 반복성 있게 동작하는지 확인하는 것입니다.

- 충격 위치가 달라질 때 추정 구역과 상대 좌표가 함께 달라지는가?
- 낙하 높이가 증가할 때 상대 충격 점수도 증가하는가?
- 같은 조건을 반복했을 때 결과의 변동이 허용 범위 안에 있는가?
- 충격을 놓치지 않고 요약 로그와 상세 파형을 함께 저장하는가?
- ADC 포화와 주변장치 오류를 결과와 분리해 기록하는가?

## 시험 구성

`5개 위치 × 3개 높이 × 5회 반복`으로 총 75회를 수행했습니다.

| 구분 | 조건 |
|---|---|
| 충격 위치 | `FL`, `FR`, `RL`, `RR`, `CENTER` |
| 낙하 높이 | `3 cm`, `5 cm`, `10 cm` |
| 고정 조건 | 같은 낙하 물체·질량, 시험판, 센서 배치, 펌웨어 |
| 회차별 증거 | 수동 조건 라벨, 요약 CSV, 상세 trace, 영상 시점 |

매 회차는 다음 순서로 진행했습니다.

```text
부팅·보정 → PZT 자가시험 → 조건 라벨 → 낙하 → 자동 캡처 → 파일 대조
```

다음 상황에서는 해당 회차를 재시험 대상으로 분류했습니다.

- ADC 값이 0 또는 4095에 지속적으로 고정됨
- 실제 충격 위치와 기대 채널이 일치하지 않음
- 요약 로그 또는 상세 파형이 누락됨
- 조건 라벨이나 영상 시점이 불명확함

## 평가 지표와 기준

| 평가 항목 | 계산·확인 방법 | 목표 |
|---|---|---:|
| 구역 정확도 | 실제 구역과 추정 구역의 일치 건수 ÷ 유효 표본 수 | ≥ 85% |
| 상대 좌표 오차 | `sqrt((x̂-x)² + (ŷ-y)²)`의 평균 | ≤ 0.15 |
| 강도 증가성 | 높이와 점수의 Spearman 상관계수, 회귀 기울기 | ρ ≥ 0.80, 기울기 > 0 |
| 높이 순서 일관성 | 동일 위치에서 `3 < 5 < 10 cm`가 유지된 비율 | ≥ 80% |
| 반복성 | 동일 조건 점수의 변동계수 `CV = 표준편차 ÷ 평균 × 100` | ≤ 15% |
| ADC 포화 | `raw ≥ 4000` 또는 포화 마스크가 기록된 비율 | ≤ 5% |
| 검출·오검출 | 수동 정답과 이벤트를 1:1로 대조 | 검출 ≥ 95%, 오검출 ≤ 5% |
| 저장 성공 | 요약 로그와 상세 파형의 1:1 대응 | ≥ 99% |

위 기준은 안전 인증값이 아니라 이번 축소 시험판의 기능과 상대 성능을 확인하기 위한 내부 기준입니다.

## 검증 결과

### 위치 추정

- 전체 구역 정확도: **91.7% (66/72)**
- 평균 정규화 좌표 오차: **0.09 (N=72)**

| 실제 위치 | 구역 일치 | 평균 좌표 오차 | 유효 N |
|---|---:|---:|---:|
| FL | 14/15 | 0.07 | 15 |
| FR | 13/14 | 0.08 | 14 |
| RL | 13/14 | 0.09 | 14 |
| RR | 14/15 | 0.08 | 15 |
| CENTER | 12/14 | 0.12 | 14 |

### 충격 강도

| 낙하 높이 | 평균 상대 점수 |
|---:|---:|
| 3 cm | 0.28 ± 0.04 |
| 5 cm | 0.49 ± 0.06 |
| 10 cm | 0.78 ± 0.08 |

- 높이-점수 Spearman 상관계수: **ρ=0.88**
- 회귀 기울기: **+0.070/cm**
- `3 < 5 < 10 cm` 증가 순서 일관성: **90.9% (20/22)**

### 반복성과 데이터 품질

| 항목 | 결과 |
|---|---:|
| 반복성 CV | **9.8%** |
| ADC 포화율 | **2.7%** |
| 검출률 | **98.7% (74/75)** |
| 오검출률 | **3.3%** |
| 저장 성공률 | **100% (74/74)** |

75회 중 74회를 검출했고, 포화되지 않은 유효 표본 72회로 위치와 강도 성능을 계산했습니다. 검출된 74개 이벤트는 모두 요약 로그와 상세 파형의 쌍으로 저장됐습니다.

## 데이터 품질 확인 순서

1. 수동 조건표와 이벤트 ID를 연결합니다.
2. `valid`, `saturation`, `error_flags`를 확인합니다.
3. 요약 CSV의 `trace_path`와 상세 파형 파일을 대조합니다.
4. 유효하고 비포화인 표본만 위치·강도 지표에 사용합니다.

## 백업과 재현성

1. 실험 세션 종료 직후 microSD 원본을 날짜·세션 폴더로 복사합니다.
2. 원본은 수정하지 않고 읽기 전용 백업을 별도로 보관합니다.
3. 실험 조건, 센서 배치, 설정값, 사진과 펌웨어 커밋 해시를 함께 기록합니다.
4. 공개 GitHub에는 개인정보를 제거한 대표 데이터와 분석 결과만 게시합니다.

## 결과의 적용 범위

이 결과는 사용한 축소 시험판, 센서 부착 방식, 낙하 물체와 높이 조건 안에서만 유효합니다. 좌표는 실제 파손 위치의 mm 값이 아니라 시험판 내부의 상대 위치이며, 점수와 점검 등급은 실제 EV 배터리의 손상·화재 위험·주행 안전을 판정하지 않습니다.
